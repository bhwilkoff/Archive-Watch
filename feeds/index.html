Playlists for other players

M3U playlists for VLC, Kodi, Jellyfin, Plex, Infuse and other players that open a playlist address. They list only films that are public domain by age, and each one plays its file from the Internet Archive.

For AI assistants

An MCP server that searches these films and answers with links that play: https://archivewatch-pulse.benwilkoff.workers.dev/mcp (Streamable HTTP, no sign-in). It keeps no record of what is asked.
