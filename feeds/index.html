Playlists for other players

Archive Watch's public-domain films as an M3U playlist. Add this one address to your player and it stays current: it is rebuilt every time the catalog is.

https://archivewatch.org/feeds/films.m3u

It lists only films that are public domain by age, and each one plays its file from the Internet Archive. Players that open a playlist address include UHF (Apple TV, iPhone, iPad and Mac), VLC, Kodi, Jellyfin, Plex, Infuse and TiviMate.

By kind:

  • Feature films
  • Silent films
  • Short films
  • Animated films

Program guide

What each Archive Watch channel is playing, as an XMLTV guide: https://archivewatch.org/feeds/guide.xml

For AI assistants

An MCP server that searches these films and answers with links that play: https://archivewatch-pulse.benwilkoff.workers.dev/mcp (Streamable HTTP, no sign-in). It keeps no record of what is asked.
